# Модели распознавания лица

Для третьего фактора поместите модель ArcFace `ms1mv3_arcface_r100.onnx` в эту папку. Модель ориентиров `2d106det.onnx` используется для выравнивания лица, если она установлена. Веса получайте у правообладателя и используйте на его условиях. [Условия InsightFace](https://github.com/deepinsight/insightface#license)

После добавления моделей пересоберите настольное приложение или образ Docker. Без модели ArcFace проверка лица недоступна. Qt-приложение запускается и поддерживает вход с паролем и кодом.
