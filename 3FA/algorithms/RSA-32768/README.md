# Проект WinNTL-11.6.0

Генератор простых чисел и RSA криптография на базе библиотеки NTL.

## Требования

- CMake 3.15 или выше
- MinGW с g++ (или другой C++ компилятор)
- Windows (или Unix-подобная система)
- **OpenSSL** (опционально, для проверки простоты чисел)

### Установка OpenSSL (опционально)

OpenSSL используется для независимой проверки простоты сгенерированных чисел. Если OpenSSL не установлен, программа будет работать, но проверка через OpenSSL будет недоступна.

**Windows:**
- Скачайте Win32OpenSSL с https://slproweb.com/products/Win32OpenSSL.html
- Или используйте vcpkg: `vcpkg install openssl`
- Убедитесь, что OpenSSL находится в PATH или укажите путь через переменные окружения

**Linux (Debian/Ubuntu):**
```bash
sudo apt-get install libssl-dev
```

**Linux (RHEL/CentOS/Fedora):**
```bash
sudo yum install openssl-devel
# или для Fedora:
sudo dnf install openssl-devel
```

**macOS:**
```bash
brew install openssl
```

После установки OpenSSL пересоберите проект - CMake автоматически найдет OpenSSL и включит проверку.

## Скрипты сборки

### `build.bat` - Сборка проекта
Собирает библиотеку NTL и приложение `prime_generator`.

**Использование:**
```cmd
build.bat
```

**Что делает:**
1. Создает директорию `build_cmake` (если не существует)
2. Настраивает CMake с генератором MinGW Makefiles
3. Собирает библиотеку NTL
4. Собирает приложение `prime_generator`

### `run.bat` - Запуск программы
Запускает уже собранное приложение `prime_generator.exe`.

**Использование:**
```cmd
run.bat
```

**Что делает:**
1. Проверяет наличие собранного исполняемого файла
2. Запускает программу `prime_generator.exe`

**Примечание:** Перед запуском необходимо выполнить сборку через `build.bat`.

## Ручная сборка

1. Создайте директорию для сборки:
```bash
mkdir build_cmake
cd build_cmake
```

2. Настройте CMake:
```bash
cmake .. -G "MinGW Makefiles"
```

3. Соберите библиотеку NTL:
```bash
cmake --build . --target ntl
```

4. Соберите приложение:
```bash
cmake --build . --target prime_generator
```

## Результат сборки

После успешной сборки исполняемый файл будет находиться в:
- `build_cmake/prime_generator.exe` (Windows)
- `build_cmake/prime_generator` (Unix)

## Использование программы

### Запуск через скрипт

```cmd
run.bat
```

### Прямой запуск

```bash
cd build_cmake
./prime_generator.exe
```

### Запуск с параметрами командной строки

```bash
./prime_generator.exe 1024 my_prime
```

Где:
- `1024` - размер простого числа в битах
- `my_prime` - имя файла для сохранения

## Функциональность программы

После запуска программа откроет консольный интерфейс для:

- **Генерации простых чисел** различных размеров (256, 512, 1024, 2048, 4096 бит)
- **Сохранения простых чисел** в файлы (директория `generated_primes` в корне проекта)
- **Генерации RSA ключей** на основе простых чисел
- **Шифрования и расшифровки данных** с использованием RSA
- **Управления ключами** (сохранение, загрузка, список доступных ключей)

## Структура проекта

- `CMakeLists.txt` - конфигурация CMake
- `build.bat` - скрипт сборки
- `run.bat` - скрипт запуска
- `main.cpp` - главный файл приложения
- `RSACrypto.cpp/h` - реализация RSA криптографии
- `RSAKeyManager.cpp/h` - управление RSA ключами
- `PrimeFileManager.cpp/h` - управление файлами простых чисел
- `BigInt.h` - обертка для работы с большими числами NTL
- `src/` - исходные файлы библиотеки NTL
- `include/` - заголовочные файлы библиотеки NTL
- `build_cmake/` - директория сборки (создается автоматически)
- `generated_primes/` - директория для сохранения простых чисел (создается автоматически)
- `rsa_keys/` - директория для сохранения RSA ключей (создается автоматически)
