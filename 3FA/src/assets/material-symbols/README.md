The bundled font is a static subset of [Google's Material Symbols Rounded](https://github.com/google/material-design-icons/tree/27e9ef1dbeedc13d682fece4a58e1eda4cb0961a/variablefont). The subset retains only the Unicode glyphs listed in `src/apptheme.cpp` and fixes the axes at `FILL=0`, `GRAD=0`, `opsz=24`, and `wght=400`. The 3FA executable embeds the font as a Qt resource.
